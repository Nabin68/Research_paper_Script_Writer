## 1. HOOK STRENGTH TEST
 
### Must Have:
- [ ] Opens with a **pattern-interrupting** statement
- [ ] **Under 15 words** for maximum impact
- [ ] Includes **specific numbers** or metrics
- [ ] Creates **immediate curiosity**
- [ ] **Challenges existing beliefs** or expectations
 
### Must Avoid:
- [ ] NO generic openings ("This company...", "Did you know...")
- [ ] NO creator-focused starts ("I just discovered...")
- [ ] NO speculation words ("could", "might", "maybe")
- [ ] NO slow build-ups before the hook

## 3. RETENTION ELEMENTS
 
### Pattern Interrupts:
- [ ] Contains "But here's where it gets interesting..." (or equivalent)
- [ ] Has **tension-building phrases** every 5-10 seconds

## 4. CREDIBILITY CHECK
 
### Numbers & Proof:
- [ ] Uses **specific numbers** (not "thousands" but "2000")
- [ ] Includes **named sources** when applicable
- [ ] Has **before/after comparisons** or contrasts
- [ ] Contains **proof elements** (screenshots, data, examples)
 
### Authority Elements:

### Sentence Structure:
- [ ] Primarily **short, punchy sentences** (8-12 words)

- [ ] Uses **power words** (genius, crazy, hidden, massive)
